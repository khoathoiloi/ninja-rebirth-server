Hướng Dẫn Kết Nối Client (APK)

Để game client trỏ về máy chủ cá nhân của bạn:

  1. Cách 1 (Sửa cấu hình APK): Đổi nội dung file assets/QHinfo thành địa chỉ IP máy tính chạy server (ví dụ: http://192.168.1.x:8080).
  2. Cách 2 (Giả lập / Root): Sửa file /etc/hosts trong điện thoại/giả lập để trỏ domain hoặc IP 47.75.231.164 về máy tính của bạn.
